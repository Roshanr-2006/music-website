Project Overview

What is SoundWave?

SoundWave is a fully responsive music website template built as a college project to demonstrate front-end web development skills. It features a rich UI, interactive music player, artist profiles, and a validated contact form — all without a backend.

This project was built with pure HTML5, CSS3, and Vanilla JavaScript — no frameworks, no libraries beyond Font Awesome and Google Fonts. Everything you see is hand-coded from scratch.

Capabilities

Website Features

Everything this template includes out of the box

Fully Responsive

Optimized for Desktop, Tablet, and Mobile devices using CSS Grid, Flexbox, and media queries.

Music Player

Working audio player with play/pause, progress bar, seek, and single-song-at-a-time enforcement.

Dark / Light Theme

Toggle between dark and light mode. Preference is saved in localStorage across sessions.

Search & Filter

Real-time search by song title, artist name, or genre. Filter results by specific artist.

Favorites Playlist

Add songs to favorites with one click. Persisted in localStorage so your list survives page refresh.

Form Validation

Contact form with real-time validation: email format, 10-digit phone, 200-word message limit.

Toast Notifications

Animated success, error, info, and warning toasts shown for all user interactions.

Artist Profiles

Dedicated artist pages with biography, stats, songs list, social links, and contact info.
